Shadow Protocol is an original top-down stealth game: sneak through three hand-designed floors past patrolling guards with visible vision cones, hide in shadows and behind crates, listen for footsteps, grab the keycard and reach the glowing exit unseen. A suspicion meter that decays when you break line of sight gives every near-miss a chance to recover, while sprinting is loud and lit floors betray you — patience and timing win.

## Run it

```sh
node serve.ts
```
